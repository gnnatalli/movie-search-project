# Movie Search Project

Консольное приложение для поиска фильмов в учебной базе данных MySQL Sakila.

Приложение позволяет искать фильмы по ключевому слову, жанру и диапазону годов. Информация о поисковых запросах сохраняется в MongoDB и используется для отображения статистики.

## Возможности проекта

* поиск фильмов по слову в названии;
* поиск фильмов по жанру;
* фильтрация по диапазону годов;
* вывод результатов страницами по 10 фильмов;
* сохранение истории запросов в MongoDB;
* просмотр последних запросов;
* просмотр популярных запросов;
* обработка некорректного пользовательского ввода.

## Используемые технологии

* Python 3;
* MySQL;
* база данных Sakila;
* MongoDB;
* mysql-connector-python;
* PyMongo;
* Git и GitHub.

```text
movie-search-project/
```

### Описание файлов

* `main.py` — точка входа, главное меню и обработка команд пользователя.
* `mysql_connector.py` — подключение к MySQL и выполнение поисковых запросов.
* `log_writer.py` — сохранение поисковых запросов в MongoDB.
* `log_stats.py` — получение последних и популярных запросов.
* `output_formatter.py` — форматирование результатов в консоли.
* `local_settings_example.py` — пример настроек подключения.
* `requirements.txt` — список необходимых библиотек.
* `.gitignore` — список файлов, которые не должны попадать в Git.

## Установка проекта

Клонируйте репозиторий:

```bash
git clone https://github.com/gnnatalli/movie-search-project.git
```

Перейдите в папку проекта:

```bash
cd movie-search-project
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

## Настройка подключения

Скопируйте файл:

```text
local_settings_example.py
```

Переименуйте копию в:

```text
local_settings.py
```

Укажите в нём собственные данные подключения к MySQL и MongoDB.

Файл `local_settings.py` не загружается в GitHub, поскольку он может содержать конфиденциальные данные.

## Запуск программы

Запустите файл:

```bash
python main.py
```

После запуска появится главное меню:

```text
1. Поиск фильма по ключевому слову
2. Поиск фильма по жанру и году
3. Статистика поисковых запросов
0. Выход
```

## Работа с базами данных

MySQL используется для получения данных о фильмах из базы Sakila.

MongoDB используется для сохранения:

* даты и времени запроса;
* типа поиска;
* параметров поиска;
* количества показанных результатов.
