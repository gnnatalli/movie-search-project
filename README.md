# Movie Search Project

Приложение для поиска фильмов в учебной базе данных MySQL Sakila.

Проект имеет два интерфейса:

- консольное приложение;
- веб-интерфейс на FastAPI.

Приложение позволяет искать фильмы по ключевому слову, жанру и диапазону годов. Информация о реальных поисковых запросах сохраняется в MongoDB и используется для формирования статистики.

## Возможности проекта

* поиск фильмов по слову или части названия;
* регистронезависимый поиск по названию;
* поиск фильмов по жанру;
* фильтрация по диапазону годов;
* вывод результатов страницами по 10 фильмов;
* переход между страницами результатов;
* сохранение поисковых запросов в MongoDB;
* сохранение общего количества найденных фильмов;
* отображение 5 последних уникальных запросов;
* отображение 5 самых популярных запросов;
* подсчёт количества повторений поисковых запросов;
* пагинация не учитывается как новый поисковый запрос;
* обработка некорректного пользовательского ввода;
* консольный интерфейс;
* веб-интерфейс;
* автоматические тесты с pytest.

* `main.py` — запуск консольного приложения, главное меню и обработка команд пользователя.

* `log_writer.py` — сохранение поисковых запросов в MongoDB.
* `log_stats.py` — получение 5 последних уникальных и 5 самых популярных запросов.
* `output_formatter.py` — форматирование результатов и статистики в консоли.
* `web_app.py` — веб-приложение на FastAPI.

* `tests/test_project.py` — автоматические тесты проекта.
* `local_settings_example.py` — пример настроек подключения к базам данных.
* `requirements.txt` — список необходимых библиотек.
* `.gitignore` — список файлов, которые не должны попадать в Git.

## Установка проекта

Клонируйте репозиторий:

```bash
git clone https://github.com/gnnatalli/movie-search-project.git
```

Перейдите в папку проекта:

```bash
cd movie-search-project
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

## Настройка подключения

В репозитории находится пример файла настроек:

`local_settings_example.py`

Создайте на его основе файл:

`local_settings.py`

и укажите в нём корректные данные подключения к MySQL и MongoDB.

Файл `local_settings.py` добавлен в `.gitignore` и не загружается в GitHub, поскольку содержит конфиденциальные данные подключения.

## Запуск консольного приложения

Запустите:

```bash
python main.py
```

После запуска появится главное меню:

```text
1. Поиск по ключевому слову
2. Поиск по жанру и диапазону годов
3. Статистика поисковых запросов
0. Выход
```

## Запуск веб-интерфейса

Запустите FastAPI:

```bash
python -m fastapi dev web_app.py
```

После запуска откройте в браузере:

```text
http://127.0.0.1:8000
```

Веб-интерфейс позволяет выполнять поиск фильмов и просматривать статистику поисковых запросов.

## Работа с MySQL

MySQL используется для получения информации о фильмах из базы данных Sakila.

Реализованы:

* поиск по слову или части названия;
* регистронезависимый поиск;
* поиск по жанру и диапазону годов;
* получение списка жанров;
* получение доступного диапазона годов;
* пагинация по 10 фильмов;
* подсчёт общего количества найденных фильмов.

Для регистронезависимого поиска используется SQL-функция `LOWER()`, а пользовательский ввод приводится к нижнему регистру с помощью метода `.lower()`.

## Работа с MongoDB

MongoDB используется для сохранения поисковых запросов.

Для каждого реального поиска сохраняются:

* `timestamp` — дата и время запроса;
* `search_type` — тип поиска;
* `params` — параметры поиска;
* `results_count` — общее количество найденных фильмов.

Переход между страницами результатов не создаёт новый поисковый запрос в статистике.

На основе сохранённых данных формируются:

* 5 последних уникальных поисковых запросов;
* 5 самых популярных поисковых запросов.

Для популярных запросов также отображаются:

* количество выполнений;
* количество найденных результатов;
* дата последнего выполнения запроса.

## Тестирование

Для автоматического тестирования используется pytest.

Запуск тестов:

```bash
python -m pytest -v
```

Тесты проверяют основные функции проекта:

* подключение к MySQL;
* получение жанров;
* получение диапазона годов;
* поиск по ключевому слову;
* поиск по жанру и диапазону годов;
* пагинацию;
* подсчёт общего количества результатов;
* запуск веб-интерфейса FastAPI.
